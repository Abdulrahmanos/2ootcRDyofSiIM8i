# Evidence index

These artifacts are generated by section 9 of [the notebook](../01_monreader_baseline.ipynb). They preserve the evidence behind the README and writing drafts. They contain metadata and predictions rather than source image pixels.

| File | What can be checked |
| --- | --- |
| [results.md](results.md) | Generated summary of scores and interpretation |
| [metrics.json](metrics.json) | Settings, package versions, dataset and code hashes, confusion counts, and metrics |
| [dataset_manifest.csv](dataset_manifest.csv) | Relative image paths, labels, splits, video IDs, frame numbers, dimensions, modes, and file hashes |
| [validation_predictions.csv](validation_predictions.csv) | Every training frame's held-out fold, true label, and predictions from both models |
| [test_predictions.csv](test_predictions.csv) | Supplied test labels, logistic predictions, and flip probabilities |
| [validation_metrics.csv](validation_metrics.csv) | Pooled and fold-summary results for the two models |
| [fold_metrics.csv](fold_metrics.csv) | Each model's five validation scores |
| [fold_summary.csv](fold_summary.csv) | Fitting/validation sizes, validation group counts, and class balance |
| [validation_confusion_matrix.csv](validation_confusion_matrix.csv) | Rows are actual labels; columns are predicted labels |
| [validation_confusion_matrix.png](validation_confusion_matrix.png) | Visual summary of grouped errors |
| [f1_comparison.png](f1_comparison.png) | Scores with their evaluation protocols labeled |

Recalculate the grouped headline scores without loading the images, from the project root:

```python
import pandas as pd
from sklearn.metrics import f1_score

oof = pd.read_csv("reports/validation_predictions.csv", dtype={"video_id": str})
assert oof.groupby("video_id")["fold"].nunique().eq(1).all()
print(f1_score(oof["target"], oof["logistic_pixels_prediction"]))
print(f1_score(oof["target"], oof["always_flip_prediction"]))
```

The expected pooled scores for the recorded run are 0.8567870485678705 and 0.6539110861001688. The fold column identifies the validation fold, with the other four folds forming its fitting set. IDs are preserved as strings to retain leading zeros.

Recalculating metrics checks consistency of the exported labels and predictions. It does not independently prove that the training process excluded those groups; inspect the executable fold construction and assertions in the notebook for that evidence. Repeating training requires the source images.
